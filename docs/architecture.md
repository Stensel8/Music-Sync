# Architectuur

## Overzicht
- **backend**: bevat de API-authenticatie en sync-logica.
- **frontend**: eenvoudige webpagina als interface.
- **database**: (optioneel) opslag van gegevens voor later gebruik.

## Modules
- **auth**: Spotify, Tidal (en eventueel Deezer) authenticatie.
- **services**: Logica om nummers te matchen en te synchroniseren.
