Set up {{ label }}

Music-Sync talks to {{ label }} through a developer app of your own. Making one takes a few minutes, and you only do it once.

{% if configured %}
{{ label }} has a client ID. Log in with {{ label }}
{% elif checked %}
There is no {{ label }} client ID in the settings file yet. Did you save the file?
{% endif %}

  1. Create an app

    Open the {{ label }} developer dashboard, log in with your {{ label }} account and click {{ 'Create app' if service == 'spotify' else 'Create New App' }}.

    {% if service == 'spotify' %}

    Spotify only lets apps of Premium accounts use its API. Without Premium, someone who has it can make the app and add you under User Management.

    {% endif %}

    Open the {{ label }} developer dashboard ↗

  2. Fill it in

    Name and description can be anything. As redirect URI, use exactly:

    {{ redirect_uri }}
    {% if service == 'spotify' %}

    Under Which API/SDKs are you planning to use? tick Web API and nothing else.

    {% else %}

    Allow the scopes collection.read, collection.write, playlists.read, playlists.write and user.read.

    {% endif %}

  3. Copy the {{ 'Client ID' if service == 'spotify' else 'Client ID and Client Secret' }}

    {% if service == 'spotify' %}

    Save the app, open its Settings and copy the Client ID. The client secret is not needed.

    {% else %}

    Copy the Client ID and the Client Secret of the app. The secret lets Music-Sync search Tidal's catalogue.

    {% endif %}

  4. Paste it into your settings file

    Open this file in a text editor. It is in a hidden folder, so open it by its path:

    {{ config_file }}

    Put what you copied between the quotes under [{{ service }}], and save the file:

    [{{ service }}]
client_id = "paste the Client ID here"{% if service == 'tidal' %}
client_secret = "paste the Client Secret here"{% endif %}

  5. Come back here

    Music-Sync notices the saved file by itself; there is no need to restart it.

    Done: log in with {{ label }}
